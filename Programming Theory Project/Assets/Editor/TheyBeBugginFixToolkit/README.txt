THEY BE BUGGIN — UNITY 6 PROJECT FIXER

1. Back up the Unity project or commit it to version control.
2. Close Play Mode.
3. Place TheyBeBugginProjectFixer.cs in Assets/Editor.
4. IMPORTANT: Remove or rename the previous TheyBeBugginProjectFixer.cs if installed.
5. Wait for Unity to compile.
6. Open Tools > They Be Buggin > Project Fixer.
7. Click Preview Fixes, review findings, then Back Up and Apply Fixes.
8. Test gameplay. Backups and fix_report.txt are saved outside Assets in TheyBeBugginFixBackups.

Designed against the uploaded Scan_20261023_233353.zip source (Unity 6000.0.76f1).
Does not rewrite movement algorithms and cannot guarantee a bug-free project.
This script has not been compiled or executed in the user's Unity Editor.
